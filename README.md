# E-commerce: категории и товары

Учебный проект по объектно-ориентированному программированию (ООП).

В проекте реализованы два основных класса:

- `Product` — товар интернет-магазина с названием, описанием, ценой и количеством.
- `Category` — категория товаров с названием, описанием и списком товаров.

## Основные возможности

### Класс Product

- Создание товара с помощью конструктора.
- Создание товара из словаря через метод `new_product()`.
- Приватный атрибут цены `__price`.
- Получение и изменение цены через свойство `price`.
- Проверка цены: она должна быть больше нуля.

### Класс Category

- Хранение списка товаров в приватном атрибуте `__products`.
- Добавление товаров через метод `add_product()`.
- Получение информации о товарах через свойство `products`.
- Подсчёт количества созданных категорий (`category_count`).
- Подсчёт общего количества товаров (`product_count`).

### Загрузка данных

Категории и товары загружаются из JSON-файла `data/products.json` с помощью функции `load_categories()`.

## Установка

```bash
poetry install
```

## Запуск приложения

```bash
poetry run python main.py
```

## Тестирование

Запуск тестов:

```bash
poetry run pytest
```

Проверка покрытия кода:

```bash
poetry run pytest --cov=src --cov-report=term-missing
```

Создание HTML-отчёта:

```bash
poetry run pytest --cov=src --cov-report=html:coverage_report
```

HTML-отчёт находится в папке `coverage_report/`.

poetry run flake8 src tests main.py
